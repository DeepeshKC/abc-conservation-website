
# ABC Conservation Website

A responsive, nature-focused website concept for an environmental conservation organisation.

## Website sections

- Home
- About
- Our Work
- Nature
- Stories
- Contact

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- SVG favicon

No frontend framework or build process is required.

## Preview locally

Open `index.html` in a web browser. For a more reliable local preview, use a simple local development server.

## Deploy with Cloudflare Pages

1. Sign in to Cloudflare.
2. Open Workers & Pages.
3. Choose Create application and then Pages.
4. Connect the GitHub repository `abc-conservation-website`.
5. Select the production branch, usually `main`.
6. Leave the build command empty.
7. Set the build output directory to `/`.
8. Deploy the website.

The site is static, so no build command is required.

## Customisation

Update `js/config.js` to change the organisation name, page title, description and contact email.

Edit `index.html` to replace placeholder text and update navigation, sections and links.

Edit `css/style.css` to customise colours, spacing, typography and layout.

Replace the illustrative remote images with appropriately licensed, organisation-approved photographs before publishing.

## Important

ABC Conservation is a temporary project name. The website copy, contact email and imagery are placeholders. Verify and replace them before publishing the site publicly.

This website currently has no submission form, database or administration dashboard.
